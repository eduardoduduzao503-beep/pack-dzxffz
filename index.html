Como conectar a pasta do Drive

1. No Google Cloud Console, habilite Google Drive API no seu projeto.
2. Crie uma chave de API nova. Não use uma chave que já foi compartilhada publicamente.
3. Restrinja a chave à Google Drive API e, quando possível, ao seu domínio GitHub Pages.
4. Cole a chave acima e toque em “Carregar packs”. A chave fica no navegador durante esta sessão e não é salva pelo site.
